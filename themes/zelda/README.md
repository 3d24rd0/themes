# The Legend of Zelda: 40th Anniversary Theme

A dark, high-contrast, eye-strain-free theme inspired by the **Nintendo Switch OLED / Pro Controller Zelda Edition** and the official **40th Anniversary The Legend of Zelda** campaign palette.
